# 🎉 Party Planning at Work — Maximum Independent Set in a Tree

## Problem Description

A company hierarchy is represented as a **tree**, where each edge connects an employee with their immediate boss. The HR director wants to invite as many employees as possible to a party, with the restriction that:

> No employee can be invited if their direct boss is also invited.

The objective is to find a **maximum independent set** of the tree — the largest possible set of employees such that no two directly connected employees are invited.

The input is given as a list of edges:

```python
[parent, child]
```
## How to run
python3 party_planning.py
