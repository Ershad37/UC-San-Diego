# Merge Sort (Python)

A simple implementation of the **Merge Sort** algorithm written in Python.

## 📌 Overview

Merge Sort is a **divide-and-conquer** sorting algorithm that:

1. Splits the list into halves
2. Recursively sorts each half
3. Merges the sorted halves together

It guarantees a time complexity of **O(n log n)**.
